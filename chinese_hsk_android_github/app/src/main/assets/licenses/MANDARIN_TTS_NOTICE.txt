Offline Mandarin text-to-speech voice pack

This application bundles Kokoro v1.1-zh, published by hexgrad, through the sherpa-onnx Kokoro multi-language package. The model card identifies it as Apache License 2.0. The bundled sherpa-onnx Android runtime is v1.13.8 and is also Apache License 2.0. The complete model and runtime license texts are included in this directory.

Model card and license: https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh
Android-ready package: https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/kokoro-multi-lang-v1_1.tar.bz2
Model documentation and voice samples: https://k2-fsa.github.io/sherpa/onnx/tts/all/Chinese-English/kokoro-multi-lang-v1_1.html
Runtime source: https://github.com/k2-fsa/sherpa-onnx/tree/v1.13.8

The full-precision model emits 24 kHz audio. The model package has 103 total speakers; the app exposes only the 100 Mandarin voices (55 female and 45 male). The model does not label speaker ages, so character age is represented with a very small playback-pitch adjustment while preserving the assigned female or male Mandarin voice. Speech is synthesized locally from the current dialogue text; the app does not download replacement lines or depend on paid services.
